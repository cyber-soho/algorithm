Sequential (Linear) Search

The simplest searching algorithm in Computer Science. It starts at the first item and checks each one in order until the target is found or the list ends.

How It Works

  1. Start at index 0 (the first element)
  2. Compare current element to the target
  3. Match found? → Return the index. Done!
  4. No match? → Move to the next element
  5. End of list reached? → Target is not present. Return -1

When to Use

👍 Best For:
  • Small datasets (under ~100 items)
  • Unsorted or unordered data
  • One-time searches (not worth sorting first)
  • Linked lists (no random access available)
👎 Avoid When:
  • Large sorted datasets
  • Repeated searches on same data

Best Case

O(1)

Target is the very first item.

Average Case

O(n)

Check about half the items.

Worst Case

O(n)

Target is last or totally absent.

⚡

Binary Search

A "divide and conquer" algorithm that repeatedly divides the search space in half. It is dramatically faster than Sequential Search but has one strict rule: The data MUST be sorted.

The Logic Steps

Step 1

Set low to first index and high to last index.

Step 2

Calculate middle:
mid = (low + high) / 2

Step 3 (Compare)
  • Equal? Found it!
  • Mid > Target? Search LEFT half.
  • Mid < Target? Search RIGHT half.

The Power of Halving

Compare the maximum number of steps required to guarantee a result based on the dataset size.

Performance Metrics

  • Best Case Time O(1)
  • Average Case Time O(log n)
  • Worst Case Time O(log n)
  • Space Complexity O(1) (Iterative)

The Crucial Tradeoff

Binary search requires random access (like arrays, not linked lists) and data MUST be pre-sorted.

Sorting costs time (usually O(n log n)). It is only worth paying this cost if you intend to search the same dataset multiple times.

🎯

Greedy Algorithm Strategy

Not a specific algorithm, but a problem-solving strategy. At each step, you make the locally optimal choice hoping it leads to a globally optimal solution. Once a choice is made, it's final. No backtracking.

1. Greedy Choice Property

Making the locally best choice at each step leads to the globally best solution. You never need to "undo" a decision.

2. Optimal Substructure

The best overall solution contains the best solutions to its sub-problems.

Key Takeaway

Sequential is simple and flexible. Binary is strict but wildly efficient. Greedy makes fast local decisions but requires mathematical proof to guarantee global success.
